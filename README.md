# Osaurus Beta

Internal and beta-testing builds of [Osaurus](https://github.com/osaurus-ai/osaurus).

- Download the latest build from [Releases](https://github.com/osaurus-ai/osaurus-beta/releases).
- Osaurus Beta installs alongside stable Osaurus and updates automatically via Sparkle.

These builds are for internal and beta testing only. Not for redistribution.
